# School Management App

A Flutter application for school management system.

## Project Setup

1. Clone the repository:
```bash
git clone https://github.com/huyIT203/schoolmanagement-.git
```

2. Switch to dev_FE branch:
```bash
git checkout dev_FE
```

3. Install dependencies:
```bash
flutter pub get
```

## Development

To push changes to the repository:

```bash
git add .
git commit -m "Your commit message"
git push origin dev_FE
```
